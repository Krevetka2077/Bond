# Bond — локальный анализ портфеля

Веб-приложение для сравнения текущего портфеля с двумя вариантами распределения капитала. Работает локально в браузере, принимает исторические цены в CSV и использует [Riskfolio-Lib](https://github.com/dcajasn/Riskfolio-Lib) для оптимизации.

## Возможности

- Выбор активов из загруженного CSV и ввод текущих долей.
- Расчёт исторической доходности, волатильности, VaR 95%, CVaR 95% и максимальной просадки.
- Распределение с минимальной дисперсией и с максимальным отношением ожидаемой доходности к риску.
- Минимальная и максимальная доля для каждого актива.
- Сравнение портфелей и выгрузка долей в CSV.

## Быстрый запуск на Windows

Требуется Python 3.14 и доступ в интернет при первой установке зависимостей.

```powershell
git clone https://github.com/Krevetka2077/Bond.git
cd Bond
.\run.bat
```

Скрипт создаст виртуальное окружение и запустит Streamlit. Откройте адрес, показанный в терминале (обычно <http://localhost:8501>). Котировки из интернета приложение не получает.

Ручной запуск для других систем:

```bash
python -m venv .venv
# Активируйте .venv для вашей оболочки
python -m pip install -r requirements.txt
python -m streamlit run app.py --browser.gatherUsageStats false
```

## Формат данных

CSV должен содержать столбец `Date` в формате `YYYY-MM-DD`, затем по одному столбцу цен на актив. Пример:

```csv
Date,AAA,BBB
2024-01-02,100.00,80.00
2024-01-03,101.20,79.50
```

Нужно минимум 31 наблюдение и два актива. Даты должны быть уникальными, а цены — положительными и без пропусков. Для корректной оценки полной доходности используйте цены с поправкой на сплиты и дивиденды. В интерфейсе можно скачать [пример](data/example_prices.csv) с семью активами и 504 строками; он подготовлен из файла `examples/Assets.xlsx` репозитория Riskfolio-Lib.

После загрузки выберите активы и частоту данных. В таблице задайте текущие доли (сумма 100%) и допустимые границы для оптимизации. Текущие доли могут выходить за новые ограничения: это исходный вариант для сравнения.

## Методика и ограничения

Оптимизация повторяет схему [Tutorial 1 — Classic Mean Risk Optimization](https://github.com/dcajasn/Riskfolio-Lib/blob/master/examples/Tutorial%201%20-%20Classic%20Mean%20Risk%20Optimization.ipynb): исторические оценки доходности и ковариации, модель `Classic`, мера риска `MV`, цели `MinRisk` и `Sharpe`. Ограничения на доли задаются линейными неравенствами Riskfolio-Lib.

Годовая доходность — средняя доходность за период × 252, 52 или 12; волатильность масштабируется квадратным корнем из этого числа. VaR и CVaR показывают оценку потерь **за один период** на уровне 95%. Максимальная просадка рассчитана по исторической траектории при восстановлении целевых долей после каждого периода.

Историческая оптимизация не прогнозирует будущую доходность. Комиссии, налоги и проскальзывание не учитываются. QuantLib в этой версии не используется; его можно подключить позже для оценки облигаций и производных инструментов.
